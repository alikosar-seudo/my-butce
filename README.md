# My Bütçe — Android test sürümü

Bu depo kaydı yalnızca v0.1.0-test APK yayınının sürüm bilgilerini içerir.

APK gelir/gider takibi, yerel SQLite saklama ve Türkçe sesli komut altyapısı sunar. Finansal kayıt için açık onay gerekir.

Paket Android Debug test anahtarıyla imzalanmıştır; üretim mağaza sürümü değildir. Android 7.0 ve üzeri, ARM64/x86_64 desteklidir. Gerçek Türkçe mikrofon tanıması ve bildirim teslimi henüz telefonda doğrulanmadı.

APK ve SHA256SUMS dosyası GitHub Releases üzerinden paylaşılacaktır.
